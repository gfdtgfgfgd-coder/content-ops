# GLM5.3 封面对照分析与两条生图提示词

2026-11-03，按用户最新成图反馈修订。原始四图提示词未提供，最初按成图反推；本轮两图中，图一是用户自行改好的认可方向，图二是旧提示词实际生成的简化版。当前以新图一为编程版基准。

## 这次为什么生成偏了

旧提示词明确要求「删除环绕功能牌、底部四栏、背景光轨」，屏幕「只展示」三行任务词，又把「任务示意」列入准确可见文字。成图正好执行了这些指令。问题在提示词的取舍：把功能信息模块误当作装饰删除了。

| 对照 | 用户改好的新图一 | 旧提示词生成的新图二 |
|---|---|---|
| 标题位置 | 靠上、两行紧凑，为主体和底栏让出位置 | 起笔更低，标题块与场景之间留出更多无信息空间 |
| 屏幕 | 暗色编辑器，行号、缩进、彩色代码建立编程场景 | 浅色屏幕只放三行大号任务词 |
| 中段 | 大笔记本、机器人、四张错位功能牌、连接光线 | 只有笔记本和机器人，功能牌整组缺失 |
| 底部 | 四栏图标、功能标题和利益解释构成完整广告信息层 | 四栏被删，增加用户未要求的「任务示意」 |
| 场景细节 | 笔筒、书本、绿植与局部光效形成空间层次 | 场景明显简化 |

最初四图中，后两图更醒目的标题方法仍可沿用：完整白蓝字面、少镜面碎反光、宽笔刷承托饱满中文。应优化主次与位置，保留商业3D内容；功能牌写名称、底栏解释用途或收益，可以同时存在。design-taste-frontend 的层级观察方法不等于极简删减要求。

## 两条修正版如何拉开

| 项目 | 提示词一 | 提示词二 |
|---|---|---|
| 内容方向 | 编程与 Agent 商业推广 | 文档整理工作流 |
| 价格短句 | 好价来袭，沿用用户最新图一 | 白菜价 |
| 视觉 | 深蓝、白蓝模型名、黄底黑字 | 蓝白紫、深蓝模型名、橙红底白字 |
| 中段 | 左大电脑、右机器人、四张错位功能牌 | 立体文档展开、右侧一条统一流程侧栏 |
| 底部 | 完整四栏图标＋标题＋副说明 | 两列用途说明 |

编程版宣传文案沿用用户自改图一，仅作本轮视觉复现素材，未独立核验其中「百万上下文」和比较、安全等主张，也未将其存为产品事实。第二版使用任务流程及用途标签，不增加性能主张。代码屏是插画中的编辑器质感，不是经过验证的产品界面或可运行 SDK 示例。两条仍是提示词交付，本轮未重新生图、未发布、未做平台重合检测，不能据此保证检测结果。

## 提示词一 · 按用户图一恢复完整编程商业海报

```text
生成一张 GLM5.3 主题的小红书商业海报，竖版3:4，1080×1440px，精致商业3D插画风格，冷蓝科技质感，信息层完整，缩至270px宽仍能辨认标题与功能牌文字。不能用三行大号中文任务词替换场景，不额外画任务示意。

【整体分区比例】
顶部标题区约占画面35%，中段场景+功能牌区约占42%，底部卖点栏约占16%，底边留白约6%。各区紧凑衔接，中间不留大面积空洞。

【标题区——上部35%，水平居中】
第一行"GLM5.3"：完整占一行，字面宽约画布88%，水平居中。超粗3D无衬线字体，白色完整正面，极浅蓝色薄侧面，轻微立体倒角；去掉镜面反射、深色切面、厚内描边与强透视变形。字形清晰连贯，不被任何物件遮挡。
第二行"好价来袭"：四字单行超粗黑体，黑字压在鲜黄色哑光宽笔刷上；色块宽约画布84%，四字大幅填满色块并留少量内边距，实字高度明显大于功能牌和底栏文字，不拉伸字形。色块水平居中，边缘有轻微毛边质感，不加金属光泽或描边。两行标题紧凑排列，"GLM5.3"底边与"好价来袭"色块顶边间距不超过30px。

【中段场景——标题下方，占画面约42%】
背景：深夜蓝 #0A1128，桌面区域为深蓝哑光材质，有轻微光泽感，不反光过度。

左侧主体：一台大型深灰色笔记本电脑，占据中段左侧约三分之二宽度，微微右倾透视，键盘可向右延展至画面中轴偏右。屏幕展示代码编辑器界面：深色背景，左侧有行号列（1至约18行），代码有缩进层级，关键词用蓝色/绿色/黄色/橙色彩色高亮，整体为插画质感代码编辑器风格；不出现大号中文字、任务清单、模型名字样，代码中的小纹理和行号属于质感细节，不受文字清单限制。

右侧功能牌：四张蓝色玻璃质感悬浮卡片，集中排列在画面右上方屏幕右侧空间，竖向阶梯错位排列（从右上至右中依次向左下微微位移），整体不超出中段区域底部、不与底栏重叠。每张卡片：宽约300px，高约90px，蓝色半透明玻璃背景+细白边框，圆角矩形；左侧有对应小图标（约36px），右侧白色中文标签，字号约28—32px，确保5字+图标+内边距可容纳，不截断文字。四张文字从上到下：
· "编程开发"（图标：代码尖括号）
· "长程Agent"（图标：节点连接）
· "百万上下文"（图标：叠层页面）
· "安全审查"（图标：盾牌勾选）
功能牌排列在笔记本屏幕右上方空间，不遮挡任何功能牌上的文字，不与底栏重叠。笔记本屏幕与功能牌之间有3至4条细蓝色光线/数据流线连接，线条细腻，不做成粗霓虹管道。

右下角机器人：一个小型白色圆头3D机器人，高度约占画面18%，站立于桌面右侧功能牌右下方，位于中段区域内，不与底栏重叠，不遮挡任何功能牌文字。机器人有蓝色发光眼睛和腰部细节，朝向笔记本方向，投影自然落在桌面。

桌面配件：左侧靠边放一个笔筒（内有几支铅笔/钢笔），一至两本深蓝书脊的书，右后方一盆小型绿植；数量克制，不堆满桌面。

【底部卖点栏——占画面约16%】
```
