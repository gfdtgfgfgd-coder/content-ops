# GLM5.3 封面对照分析与两条生图提示词

2026-11-03。四张图按用户附件顺序编号；原始提示词未提供，本次根据成图反推重写。GLM5.3 是海报主题名，两条文字供生图工具使用。按用户最新价格候选，编程版采用五字「便宜放开跑」，文档版采用三字「白菜价」；同步调整字号和色块，不增加金额、折扣、期限或额度。「放开跑」不扩写成无限量承诺。

## 差别在哪里

图一、二的模型名已经很大。三、四更容易辨认，主要来自字面的完整度、副标题的面积和画面主次。

| 维度 | 图一、图二 | 图三、图四 |
|---|---|---|
| 模型名字面 | 镜面反射、厚倒角和深蓝分割面较多，字内部明暗变化碎 | 白至浅蓝的正面更连续，蓝色侧面承担立体感，缩小后字形仍清楚 |
| 中文副标题 | 三字「促销价」嵌在有厚边框和高光的徽章内，边框占走一部分面积 | 图三红蓝笔刷配黄白字；图四黄红笔刷配黑白字，底色宽、实字饱满，笔刷直接托住文字 |
| 视觉竞争 | 光环、圆台、芯片、五块功能牌、底部四栏都带高亮边缘 | 机器人、桌面、电脑形成更容易理解的场景，局部白色主体从暗背景中突出 |
| 信息重复 | 中部功能牌和底部四栏重复同一组功能；芯片又重复模型名 | 场景更丰富，但仍有重复模型名和底部四栏过密的问题，不照搬这些部分 |
| 两张之间的区别 | 同样是中轴芯片＋周围功能牌＋底部四栏，颜色和图标变化不足以改变骨架 | 图三偏芯片与工作流，图四偏机器人与电脑，至少主体关系不同 |

四图缩至每张 270×360 做过并排查看。这个尺寸下图一、二的中部功能牌变得零碎；三、四的中文大字和机器人轮廓仍可直接辨认。图三的小代码、工作流细字也读不清，图四屏幕中的接口字样、开源书脊等都不作为本次文案来源。

本次采用 design-taste-frontend 的一秒观察、尺度对比、明暗块和视觉层级方法。保留用户喜欢的商业 3D 插画；网页专用动效、交互、图片数量、禁渐变等要求不套用到静态海报。未运行网页 inspector，不虚构设计分数。

## 两张如何拉开

| 项目 | 提示词一 | 提示词二 |
|---|---|---|
| 内容角度 | 编程任务示意 | 长文整理任务示意 |
| 价格短句 | 便宜放开跑（五字单行） | 白菜价（三字单行） |
| 明暗配色 | 深夜蓝，白色模型名，黄底黑字 | 冰灰白，深蓝模型名，橙红底白字 |
| 主体 | 一台笔记本＋一个小机器人 | 原稿、提纲纸页与钢笔 |
| 结构 | 标题居中，横向桌面，左电脑右机器人 | 标题左对齐，下方文档从左下向右上斜排 |
| 辅助文字 | 需求拆解／代码草稿／报错排查 | 提取要点／整理提纲／核对原文 |

两条改变内容角度、主物件、明暗、构图和可见文字。没有使用镜像、裁切、噪点等处理。仅凭提示词无法判断小红书的检测结果；本次没有生成图片、上传帖子或做平台检测。参考图中的百万上下文、稳定性、安全和开源等未核实主张未写入提示词。

## 提示词一 · 深色编程工作台

```text
生成一张 GLM5.3 主题的小红书商业海报，竖版3:4，1080×1440。精致3D工作台插画结合醒目的平面大字，冷蓝科技质感，整体有主次，缩成270像素宽仍能认清两行标题。

上部约40%只放两组标题。第一行“GLM5.3”完整占一行，水平居中，字面宽约画布90%，超粗无衬线字体，白色完整正面，极浅蓝色薄侧面；保留轻微立体感，去掉镜面反射、深色切面、厚描边与强透视。第二行“便宜放开跑”，五字单行超粗黑体，字号约168像素，字距约10像素，黑字压在一整块鲜黄色哑光笔刷上；笔刷宽约950像素、高约220像素，左右各留约35像素，边缘仅有轻微毛边，字形不横向拉伸。模型名仍是最大信息层，两行靠近，字与字不相连，任何物件和光效都不遮标题。

背景深夜蓝#0A1128，上部平静偏暗。下部约55%是一张深蓝哑光桌面：中左放一台大型深灰笔记本，右下站一个小型白色圆头机器人，机器人朝向电脑，不举牌。电脑是场景主角，机器人高度约全画面18%。屏幕冷白光集中照亮桌面和机器人侧面，接触阴影自然。屏幕只展示一个简洁编辑窗口，在同一窗口内左对齐放三行大字：“需求拆解”“代码草稿”“报错排查”。每行约55—60像素，浅色字，背景干净，不编造代码、成绩或复杂仪表盘。

准确可见文字仅为：“GLM5.3”“便宜放开跑”“需求拆解”“代码草稿”“报错排查”“任务示意”。最后四字以28像素浅灰字放桌面下方。全图模型名仅出现一次。左右安全边距各55像素，底部留60像素；场景与标题分开，不相互遮挡。

删除悬浮芯片、发光圆台、环绕功能牌、底部四栏、背景光轨与满屏粒子。不要金属价格徽章，不加金额、折扣、限时字样、参数或额外文字。保留大字、一个工作场景和集中光源，不堆满发光边框。
```

## 提示词二 · 明亮文档整理台

```text
生成一张 GLM5.3 主题的小红书商业海报，竖版3:4，1080×1440。明亮的3D纸本文档工作台，结合有冲击力的平面大字。采用冰灰白#EAEFF4背景、冷白纸张、深蓝文字和一处橙红色强调，纸张厚度、翻角、投影精致，整体清晰利落。

上部约40%为标题区，统一左对齐。第一行“GLM5.3”完整占一行，左缘距画布55像素，字面宽约画布88%，使用超粗深蓝色#142C5B无衬线字体，正面完整实色，只有极薄浅蓝侧面，没有镜面反射和厚描边。第二行“白菜价”，三字单行白色超粗黑体，字号约184像素，字距约10像素，放在橙红色#F04B2D笔刷上。笔刷宽约640像素、高约236像素，左右各留约34像素，三字饱满，模型名仍是最大信息层。整组轻微向右上扬，文字不扭曲、不横向拉伸，保持高对比。标题周围平静，不叠光圈、图标或道具。

下部约55%采用不对称斜向构图：左下是一叠较小的原稿纸，中部一张翻开的提纲页，右上是一张更大的整理页，物件沿左下到右上的方向展开。三组纸张尺寸与角度不同，保持原稿和提纲的场景关系，不排列成三个相同卡片。纸页使用自然冷灰投影，右侧斜放一支深蓝钢笔，少量蓝色手写痕迹作材质细节。纸面分别清晰写“提取要点”“整理提纲”“核对原文”，字号约55—60像素；其余段落只做淡淡的纸面纹理，不生成密集小字、数字图表或伪造结果。

准确可见文字仅为：“GLM5.3”“白菜价”“提取要点”“整理提纲”“核对原文”“任务示意”。最后四字以28像素深灰字放桌面下方。模型名只出现一次。左右安全边距各55像素，底部留60像素，纸张不进入标题区。

不要机器人、电脑、芯片、机房、发光圆台、悬浮功能牌、底部四栏和霓虹边框；不要米黄色背景。不要金额、折扣、限时字样或额外能力承诺。画面必须保留实体纸张场景，不做成纯文字海报。
```
