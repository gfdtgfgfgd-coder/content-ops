## 术语（2026-11-03 更新）

- **Lilith**：拍板人、最终业务决策者。
- **规划 agent**：负责需求梳理、规则沉淀、任务卡编排与风格复核把关。
- **执行 agent**：负责写代码、调脚本、抓取数据与单张任务卡执行自验（泛指当前跑任务的 agent，不与特定模型强绑定，模型报错时可用备选模型热备替换）。
- **批量 agent（即 Hanabi）**：批量图文生成、可视化交互与素材管理中枢；当模型报错或单点 agent 不稳定时，通过 Hanabi 可视化界面与批量链路保障生产不断。
- **公司网关文案模型**：生成脚本调用的写稿模型，是模型不是角色；脚本会校验网关真实型号名，与谁来复核无关。
- 历史文档中的旧角色称呼（如 Codex 等）统一按此四元分工对齐映射。
