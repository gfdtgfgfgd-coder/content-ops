2026-11-01，lilith 反馈：Hanabi 能跑，但生成质量不行，数据白扒了。

## 问题表现

**实际生成（T08 / T11 产出）：**
- 标题："安排！· GLM5.3 · 先跑一个真实任务"
- 正文：教程风格，"想了解 GLM5.3 的实际表现，可以不看评测，直接用自己平时会遇到的任务试一试...如果你是电商商家，可以试试..."

- 语气：情绪化、促销、直给卖点

## 根本原因

`scripts/gen-xhs-post.py` 第 201-206 行的 requirements 写得太保守：

```python
'requirements':[
    '每篇 title_lines 恰好三行：行动词短句、完整模型名、短卖点；无事实时用试用场景作为第三行。模型名必须逐字一致。',
    '正文约200字，白话、约3到6段，不写第一人称亲测或虚构体验。无已核验事实时仅给试用任务、步骤和核对建议，不宣称产品已具备某能力。',
    '不能写价格、促销、活动、性价比、稳定性、性能参数、上线时间等无依据内容；不照抄旧帖能力。不能把普通任务要求写成已验证能力。',
    '3–5个标签，至少一个为去空格的模型名。不含API、询价、量大管饱、具体折扣或金额。',
    '两篇文案分别用场景叙述和任务清单等不同结构，角度不同，不要只换同义词。',
    '不用"宝子们""姐妹们""闭眼冲""炸裂""不是X而是Y"或虚立误解、揭晓式破折号。不制造亲身经历。'
]
```

**问题点：**
1. "无已核验事实时仅给试用任务、步骤和核对建议" → 强制教程风格
2. "不能写价格、促销、活动、性价比" → 禁止促销语言
3. "不含...量大管饱" → 禁止了好帖里最常用的区块词

但实际好帖（思敏勾选的 16 条）**都是促销风格**，并且大量使用：
- 价格区块词："便宜量大""量大管饱""便宜又稳定""活动价"
- 促销语气："太香了""速来""赶紧冲""直接安排上"
- 情绪化表达："爱了爱了""我去""夯"

## 为什么 Codex 这么写

看 T08 任务卡第 97 行："价格数据不接 Model Price Watch（D17：那个是做调研报告用的）"

Codex 理解成：**没有详细产品资料就不能写促销**。

但实际上：
- 思敏勾选的好帖里，很多也没有详细性能参数
- 它们用的是**通用促销语言**（"量大管饱""太香了""速来"）+ **模型名** + **通用卖点**（"代码能力强""长程任务"）
- 关键是**语气和句式**，不是详细参数

## simin-persona 有没有被用上

**有**，第 199 行加载了 `skills/simin-persona/SKILL.md`。

但 requirements 的约束**比 simin-persona 更严格**，把促销语言全禁了。

simin-persona 里明确写了（第 80 行）：
> 常用词和句式：可参考「便宜量大」「活动价」「便宜接入」「好价来袭」「直接安排上」。

但 requirements 第 204 行写：
> 不含API、询价、量大管饱、具体折扣或金额。

**直接冲突。**

## 扒的数据有没有用上

**部分用了，但用错了方向。**

- T03 提炼的标题句式（`skills/xhs-title-patterns/quick.md`）**有用**：
  - 生成的标题确实用了"安排！""直接冲！"这些动词
  - 第二行是完整模型名
  - 第三行是卖点或场景
- T04 提炼的思敏偏好（`skills/simin-persona/SKILL.md`）**加载了但被 requirements 覆盖了**
- 16 条 good 帖子的实际风格（促销、情绪化、区块词）**没体现在生成结果里**

## 正确的做法应该是

改 `gen-xhs-post.py` 第 201-206 行：

**当前（错误）：**
```python
'无已核验事实时仅给试用任务、步骤和核对建议，不宣称产品已具备某能力。'
'不能写价格、促销、活动、性价比、稳定性、性能参数、上线时间等无依据内容'
'不含API、询价、量大管饱、具体折扣或金额。'
```

**应该改成：**
```python
'无已核验详细事实时，用促销口吻 + 通用卖点（代码能力、长程任务、稳定可靠等），参考好帖句式（见 xhs-title-patterns/quick.md 的 Top5 卖点）。允许使用"便宜量大""活动价""好价来袭"等区块词，禁止具体折扣数字和金额。'
'正文约200字，白话、促销语气，可列能力要点（用 ✅ emoji），结尾用"开发者们，欢迎来体验"类召唤。不写第一人称亲测或虚构体验。'
'不含API、询价、具体折扣（几折、x折）或具体金额（¥xx）。允许"便宜量大""量大管饱""活动价"。'
```
