# 生成质量修复总结（2026-11-01 23:08）

## 问题

Codex 交付的生成结果是教程风格（"想了解 GLM5.3...可以试试"），但思敏勾选的好帖都是促销风格（"便宜量大 GLM-5.2 太香了""速来"）。

## 根因

`scripts/gen-xhs-post.py` 第 201-206 行的 requirements 太保守：
- "无已核验事实时仅给试用任务、步骤和核对建议"
- "不能写价格、促销、活动、性价比"
- "不含API、询价、量大管饱"

这导致：
1. 强制教程风格
2. 禁止促销语言
3. 禁止了好帖里最常用的区块词（"量大管饱"等）

## 修复

已修改 `scripts/gen-xhs-post.py` 第 201-207 行：

**修改前：**
```python
'无已核验事实时仅给试用任务、步骤和核对建议，不宣称产品已具备某能力。'
'不能写价格、促销、活动、性价比、稳定性、性能参数、上线时间等无依据内容'
'不含API、询价、量大管饱、具体折扣或金额。'
```

**修改后：**
```python
'无详细事实时第三行用通用卖点（代码能力强、长程任务、稳定可靠等），参考 xhs-title-patterns/quick.md 的 Top5 卖点。'
'正文约200字，促销语气，白话、约3到6段。可列能力要点（用 ✅ emoji），结尾可用"开发者们，欢迎来体验"类召唤。'
'允许使用"便宜量大""量大管饱""活动价""好价来袭""便宜接入"等区块词。禁止具体折扣数字（几折、x折）和具体金额（¥xx）。'
'可用"太香了""速来""赶紧冲""直接安排上"等促销动词。'
```

schema 示例也改成促销风格：
```python
'schema':{'posts':[{'title_lines':['赶紧冲！',model,'量大管饱，代码能力强'],...}]}
```
