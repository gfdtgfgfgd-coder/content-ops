# 架构

五层，层与层之间只通过文件（JSON / Markdown / 图片）传递。任何一层都可以单独跑、单独换。

```
┌─────────────────────────────────────────────────────┐
│ 5 产出层  outputs/<日期>/                            │
│   小红书大字报图 + 文案 / 闲鱼帖 / 公众号 HTML         │
├─────────────────────────────────────────────────────┤
│ 4 生成层  scripts/gen-*                              │
│   选题 → 文案（Claude）→ 去AI味（技能/Gemini）        │
│   → 风险词过滤（rules）→ 配图（图反推 + 文生图）      │
├─────────────────────────────────────────────────────┤
│ 3 规则层  rules/ + skills/                           │
│   platform-rules / design-rules / banned-words       │
│   思敏偏好（data/wecom/preferences.md）               │
│   价格事实（Model Price Watch 接口）                  │
├─────────────────────────────────────────────────────┤
│ 2 学习层  scripts/learn-*                            │
│   从 data/ 里的帖子提炼：好标题句式、版式特征、        │
│   高频词、图反推提示词                                │
├─────────────────────────────────────────────────────┤
│ 1 采集层  scripts/fetch-*  （Codex 操控 ego 浏览器）  │
│   小红书帖 / 闲鱼帖 / 企微截图 OCR / 图片下载          │
└─────────────────────────────────────────────────────┘
```

## 数据格式

### 帖子 `data/xhs/<id>.json`、`data/xianyu/<id>.json`

```json
{
  "id": "平台内 id",
  "platform": "xhs | xianyu",
  "url": "原帖链接",
  "author": "账号名",
  "title": "标题",
  "body": "正文",
  "images": ["data/images/xhs/<id>/1.jpg"],
  "image_urls": ["原图 url，用于重下"],
  "cover_ocr": "封面大字 OCR 结果",
  "tags": ["#glm5"],
  "metrics": {"likes": 140, "collects": 0, "comments": 0, "wants": null},
  "is_pinned": false,
  "label": {"good": true, "by": "思敏", "reason": "企微勾选 2026-xx-xx"},
  "fetched_at": "2026-11-01T17:00:00+08:00",
  "source": "bookmark | pinned | keyword:xxx"
}
```

`label` 由 T04 从企微提炼后回填；闲鱼由 `metrics.wants` 排序自动打。

### 偏好 `data/wecom/preferences.md`

人读的 Markdown：思敏认为好的 10 条特征 + 反例 + 她的原话摘录（去敏）。生成层把它整段塞进提示词。

### 规则 `rules/banned-words.yaml`

```yaml
- word: 最便宜
  level: ban        # ban 禁用 / warn 提醒
  platform: [xhs, xianyu, gzh]
  replace: 便宜管饱
  reason: 广告法极限词
```

## 模型分工

| 环节 | 用谁 | 走哪 |
|---|---|---|
| 规划、规则、风格判断、文案初稿 | Claude | 公司网关 |
| 抓取、批量脚本、OCR、重命名、跑任务卡 | GPT（Codex 桌面版） | 公司网关 |
| 去 AI 味 | 先 `avoid-ai-writing` + `lieflat-less-ai-tone` 技能；不够再接 Gemini | 公司网关 |
| 图反推提示词、文生图 | 公司网关里可用的图像模型（T06 先列出有哪些） | 公司网关 |
| 公众号排版 | `gzh-design-skill` / `md2wechat` | 本地 |

## 平台区分

| | 小红书 | 闲鱼 | 公众号 |
|---|---|---|---|
| 调性 | 普一点、不油腻、不偷袭（不蹭热点骂人） | 直给，像个人卖家 | 深度、可信 |
| 核心格式 | 大字报封面 + 短正文 + 标签 | 标题 + 价格话术 + 想要数 | 长文 |
| 好坏信号 | 思敏勾选 | 想要人数 | 阅读 / 在看 |
| 价格表达 | 不说具体折扣，可说「便宜管饱」 | 可说具体 | 可说具体 |
