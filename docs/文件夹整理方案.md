# content-ops 文件夹整理方案（2026-11-01 23:30）

## 问题

Codex 做的文件结构太流水账：
- 根目录有 `启动Hanabi.app` 和 `启动Hanabi.command`，但 Hanabi 实际在 `~/Documents/ChatGPT/【探索】/content-alchemy`
- `config/`、`work/`、`tests/` 三个目录用途不明确
- `AstrBot.app` 不知道是什么
- 文档散落在 `docs/` 和根目录

## 整理原则

1. **根目录只放核心文件**：README、AGENTS、任务进度
2. **按用途分组**：数据、规则、脚本、输出、发布物
3. **工作文件放 work/**：临时配置、环境变量、测试
4. **删除无用文件**：重复的启动脚本、不知用途的 app

## 执行步骤

1. 创建 `rules/README.md` 和 `scripts/README.md`
2. 移动 `config/` 内容到 `work/`
3. 移动 `tests/` 到 `work/tests/`

- **新人友好**：README → tasks/README → 看卡干活

- **职责清晰**：发布物在 releases/，工作文件在 work/

- 所有任务卡里的路径（`data/xhs/`、`scripts/gen-xhs-post.py`）不变
