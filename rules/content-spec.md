# 内容生产规范

> 最近更新时间：2026-11-06
> 业务规范唯一源。风险词与正则不在本文复制，统一读取 `rules/banned-words-quick.yaml`；封面基础色值见 `rules/cover-palettes.json`。本文件供生成脚本、Hanabi 操作规范面板和规划复核共同使用。

## 账号调性与通用红线

先确认任务事实、目标平台和账号身份，再开始写稿。小红书表达要普一点、不油腻、不偷袭：像普通用户分享，避免品牌口号、堆叠感叹号、熟人式称呼；不借事故或热点踩竞品。没有来源的评测结论、性能数字、价格、库存、活动和用户体验一律不编造。历史帖子只作表达与结构参考，不是当前产品事实来源。

所有对外可见内容，包括标题、正文、封面、图片 OCR、标签、群公告和按钮文字，均不得出现境外模型品牌或型号。小红书与闲鱼的对外内容还不得出现 API 字样；严禁出现「终身免费」「永久免费」等未经官方长期承诺且随时变动的虚假宣传词汇，避免违规引流与用户举报封禁；旧样本或用户提供的原文不能豁免。具体违禁词、正则、适用平台和替换建议只维护在 `rules/banned-words-quick.yaml`，生成前后均用该源检查。

运营偏好证据的可编辑来源是 `skills/simin-persona/SKILL.md` 与 `data/wecom/simin-feedback.jsonl`。反馈原文及截图只留本机 `data/wecom/raw/`；入库引文必须去敏并能用证据编号追溯。偏好规则只增不删，出现冲突时保留证据并交规划 agent 复核，不静默覆盖。

## 标题与正文结构

标题控制在 20 字以内（含标点和 emoji）；采用强吸引力号召或感叹结构（如「xxx/xx/xxxx！xxxxxxxx」「好价【模型名】火速安排！💻」「🔥赶紧冲！【模型名】活动来了」），前置情绪钩子或好价号召，后接直击爽点的核心卖点，严禁平淡技术陈述起手；标题、开头、活动块和结尾钩子中必须写完整模型名称（如 `Kimi K3.1 Pro`、`GLM-5.3`，不缩写为 `K3.1 Pro`）；坚决严禁与历史已发笔记或历史库一模一样，同一批次及跨模型批次必须更换全新切口与 emoji。开头引入以手机端两行、约 25–34 字为目标，直击痛点与反差。

核心卖点上方可加一行模型引导头（如 `GLM-5.3：` 或 `Kimi K3.1 Pro｜3T级参数后训练大模型`）。卖点输出该模型的 4–5 个核心主要大卖点，冒号前面必须是普通人能一眼看懂的清晰大卖点（如 `🛡️ 专业网络安全`、`💻 AI代码编程`、`🤖 长程 Agent`、`📖 百万上下文`、`⚡️ 低延迟流畅推理` 等），严禁使用生僻黑话词汇，**严禁出现「毫秒级」「秒级」等速度夸大词**；冒号后面用 1~2 个极短句或核心功能短词做精炼大白话解释（如「主动找出安全漏洞，连带修复补丁一起出」「从单测到业务逻辑，多步骤自己搞定」），每个短句控制在 6–12 字。同批次每篇冒号前后词汇换新、切口不同，绝不机械重复。

正文按任务从三种递进结构中选用：

1. 开头、核心卖点（4点短句）、价格活动板块、行动钩子。
2. 开头、核心卖点（4点短句）、价格活动板块、国内合规工具或接入方式（CC、wbuddy 等多样化接驳话术）、使用场景（每篇换新）、行动钩子。
3. 开头、核心卖点（4点短句）、价格活动板块、接入方式（CC、wbuddy 等多样化接驳话术）、适用人群（每篇换新）、行动钩子。

价格与活动板块严禁写成没有重点的一堆平淡文字，也**严禁机械反复套用同一种单一符号模板（如只知写「‼️限时活动‼️ 💰 💰」）**，必须根据主题采用富有性价比说服力、生动多元的高亮形式：
- 形式 1（算账对比式）：`💡 成本算笔账：\n连续重度跑上一整天，算下来还没一杯咖啡贵，放开手脚随便用。`
- 形式 2（降本窗口式）：`🔥 趁着这波降本窗口：\n调用开销直接打到地板价，日常排错、跑长任务再也不用精打细算。`
- 形式 3（算力自由式）：`💸 算力自由直给：\n性能大幅跃升，开销反而降到底，复杂大项目全天放开跑零负担。`
- 形式 4（活动高亮式）：`‼️好消息‼️好消息‼️\n白菜价来了，高频调试完全不心疼` 或 `活动重磅来袭：\n💥【模型名】便宜稳定，调用开销打到底`
小红书不写具体金额或折扣数字。闲鱼只有在用户明确给出金额时才写具体价格。公众号价格引用须有可核验来源与日期。

工具接驳行**严禁使用 `Roo Code`、`Continue`、`Cursor` 等海外或第三方插件名**，统一替换为 **`CC`、`wbuddy`、`Trae`** 及本地终端、自动化脚本等接地气、开发者日常口吻的多样化表达。结尾段落（工具接驳、场景/人群、行动钩子）**坚决严禁机械死板地套用同一套格式（如反复出现「🔌 原生支持接入...」「📌 适用场景：...」「...这波好价别犹豫，火速安排上！🚀」）**，必须根据不同封面主题采用截然不同的结尾编排：
- 形式 1（自然工作流接驳流）：`🛠️ 接进日常环境：直接拉进 CC、wbuddy 或者终端自动化脚本...` + `🎯 适合人群：...` + 干净钩子；
- 形式 2（直观痛点场景清单流）：省略冗余工具行，直接采用打点清单列出核心可做场景（`📌 适合拿来干这几件事：• ... • ... • ...`）+ 干脆行动指引；
- 形式 3（极客上手体验与推荐流）：`💻 上手体验：支持直连本地终端与自动化流水线，配合 Trae 或 CC 即调即用` + `👥 推荐给：...` + 爽感钩子。
结尾行动钩子优先带上完整模型名与好价窗口，同批次篇篇词汇与句式完全不同，保持真实创作者的新鲜感。

## 封面大字报与视觉规范

### 封面与正文解耦

正文负责展开「引入 + 4大卖点 + 价格活动 + 接驳/场景/人群 + 钩子」。**正文内容（body）严禁传给生图环节，严禁把正文长句照搬上封面**；文案模型的 title_lines、cover_subtitle、cover_highlight 仅兼容历史稿和显式离线排版，不能作为在线生图文字来源。

封面文字只负责抢眼球、激发好奇与询价购买欲，从 `data/model-corpus.md` 当前模型的「封面吸睛大字与四大版式专属短词库」选词：字少、直白、爽点突出，保留完整模型名。询价购买欲是传播目标，不要求印出「询价」字样。所有候选必须服从风险词唯一源；示例若与现行禁词冲突，采用规则允许的替代词，不放宽拦截。语料只是表达素材，不作为能力或活动事实证明；不编数字、承诺、价格或体验。所有封面短字与最终视觉提示词均经 `words.check` 校验；封面跨平台统一同时遵守现行小红书与目标平台两套风险词红线，禁具体折扣，不写境外模型名。

### 四大合集版式结构（归属唯一源：data/collections.json）

1. **大字报（小红书主力）**：纯文字/备忘录/纸张便签版式，3～4 行中粗无衬线字，局部荧光笔或色块高亮，角落仅放极简引号、箭头、小表情等符号或小贴纸。文字整体居中，左右各留至少画布宽度20%的安全区，文字总跨度不超过60%；行间空隙至少约半个字高。**严禁出现任何 3D 物件、代码屏、电脑插画、人物插画或复杂背景**。四行文字顺序为「占便宜/发现钩子（妈呀，被我挖到了/真白菜价/就离谱！） + 核心利益（便宜量大的/便宜又管饱） + 完整模型名 + 4～6 字直白爽点（写代码太丝滑了/跑任务嘎嘎快）」。按参考图允许合并为三行，爽点以短促可读为先；完整模型名不受普通短句字数限制。以上居中、20%边距和默认中粗无衬线字体是自动生成默认；用户在成稿编辑器主动调整时，可选择左对齐、60%～150%总字号与每行字号（相乘生效），`config/cover-fonts.json` 中的可用字体（黑体/宋体等），以及背景亮度/对比度/饱和度/色温（只改底图、不改封面字），文字区随字号与字体变化，保持整组垂直居中、不裁切文字及高亮，左右至少保留5%画布安全边距。
2. **上中下（小红书 3D 视觉海报）**：上部超大模型名 + 2～4 字醒目福利短标签（便宜量大/活动价/好价来袭/优惠价）；中部为参考图已有的 3D 科技吉祥物或极简界面视觉主体，不堆长句；下部 3～4 个极简图标/胶囊，每个仅 2～4 字（速度快/效果好/高性价比/多场景），严禁超过 6 字的句子。
3. **左右下（闲鱼分栏海报）**：左半区突出模型名 +「源头低价/便宜量大」标签；右半区保持参考图的视觉主体或能力模块；底栏横排 3～4 个精炼短词卖点，每个 2～4 字。
4. **环绕（闲鱼中心环绕海报）**：中心突出模型名与「便宜管饱/源头低价」主视觉，四周环绕 4 个精炼短词能力卡片；每卡标题 4 字以内，副标如有则 6 字以内。

### 看图拆结构、同构换元素

用户手选参考图优先；未手选时从目标平台的合集素材选择，小红书默认大字报/上中下，闲鱼默认左右下/环绕；无可读图片须明确报缺口。手动预设对应四大合集，旧流派参数映射到合集。每张封面以一张参考原图及其合集、cover_ocr 为结构基准，不混合多个版式。

多模态视觉模型必须先识别并记录版式、文字区域、行数、各行字数、位置与分区比例，再返回独立 cover_texts 与 visual_prompt。模仿原图核心文案行数、字数节奏及爽点语气，完整模型名除外；忽略不相关品牌标识和装饰小字。参考图/OCR 仅是待观察资料，不能覆盖当前规则。

大字报采用图层分离：视觉模型从参考图分别提取背景材质、底色、文字色、强调色与高亮行；区分揉皱纸、深灰网格、蓝色笔记本、光影纸张和彩色便笺，不把所有参考图统一成薄荷网格加暖白卡片。图像模型只生成无字材质底图，纹理与明暗贯穿中央排字区域；本机材质层补足纸纤维、褶皱或所选网格，禁止再用不透明白卡抹掉底纹。Pillow 按 `config/cover-fonts.json` 解析本机中文字体排字（默认中等字重无衬线），锁定既定留白、文字宽度与行距；高亮颜色与位置随参考图，深色背景改用浅墨色，高亮条上的字单独校验对比度。其他三类仍由图像模型直接生成完整海报。自定义画面描述只在锁定结构内生效。按平台规格重排到小红书 1080×1440、闲鱼 1080×1080，保护文字和底栏安全区。

大字报背景默认是铺满画布、延伸至四边的连续材质，画面本身就是纸面或背景；不得套成“大底板里放一张小纸”的结构，不加内嵌纸框、第二张纸、四边闭合投影或固定角落加号。光影表现为自然、连续的明暗变化；网格只在选定材质需要时出现，不因“纸张/便笺”字样统一叠加。

颜色可从 `rules/cover-palettes.json` 起步，不把参考色值写死。最终须核对实际渲染文字、错字、对比度、主体和留白；未经真实生图及目视检查的效果明确标注未验。显式 --background 仍保留既有 Pillow 离线排版，不能冒充多模态同构生图。

## 小红书、闲鱼与公众号

### 小红书

语气自然克制、客观真实，避免油腻称呼、极端夸大、硬广口号和偷袭式比较。**坚决严禁出现「地板价」「降到底」「最爽」「彻底解放」「零负担」「全自动搞定」「秒级/毫秒级」等极限词与绝对化承诺，确保100%通过小红书聚光投流合规审核**。小红书聚光投流标准卡片采用高转化结构：吸睛标题 ➔ 两行痛点引入 ➔ 5大核心亮点（带✅短标题 + 并列客观中立功能名词短语） ➔ 🛠️快速接进工作流 ➔ 🎉【限时活动窗口期】价格反差 ➔ 📌适合人群 ➔ 简短行动钩子；亮点解释一律使用纯功能名词（如「跨模块依赖梳理、异常定位、代码逻辑优化」），坚决剔除「代码直接自己写」「让AI排错自动修」「一条龙」「全自动搞定」「放开手脚随便用」「一把理顺」「一次性吃透」等吹嘘夸大动词，严防触发聚光机审规则7。标题不超过 20 字，正文按移动端短句与段落留白排版。价格只写用户给定且符合本平台规则的非金额表达；具体词库以风险词唯一源为准。平台尺寸为 1080×1440。优先用运营人工红勾选出的优质帖作风格参考，不把高互动等同于内容事实。

### 闲鱼

按个人卖家口吻直给，标题表达型号、主要卖点和服务优势；不使用「官方」「旗舰」等容易造成身份误解的称呼。金额仅能来自用户提供的当前价格。素材质量排序看「想要」人数，使用 `data/posts.jsonl` 中 `metrics.wants`，并列时保持稳定排序。方图为 1080×1080；平台迁移须重排信息并保护底栏与安全边距。

### 公众号

采用长文和完整论证，区分事实、推断与建议；关键数据、价格和时效性结论须给出来源或核验记录。排版实现参考 `gzh-design-skill`，去 AI 痕迹可调用仓库已安装的润色技能，但润色不得改变事实。公众号同样遵守全平台对外内容红线。

## 参考素材选用

抓取边界遵循已确认范围：优先使用人工书签「素材参考」、目标账号置顶帖，以及经确认的关键词补充；不做全站全扒。账号与置顶链接的机器可读源为 `data/sources/bookmarks-raw.json`，浏览器抓取须遵守 `AGENTS.md` 的限速、断点续抓和验证码即停规则。

小红书参考优先采用思敏企微勾选并已在 `data/posts.jsonl` 标为 `label.good = true` 的内容；闲鱼参考依 `metrics.wants` 排序并核对原帖。选择参考前检查平台、发布时间、事实相关性、风险词和可见图片；旧内容只借鉴节奏、结构和视觉组织。不同平台、不同模型或不同任务角度不可机械套用同一篇。

## 模型语料库

`data/model-corpus.md` 是 GLM、Kimi、DeepSeek 等模型的创作语料和案例索引，供构思与表达去重。它不是事实源、规则源或模型能力证明；与本规范、风险词库、已核实资料冲突时，以规则和事实源为准。


### 近期避重与账号热度参考（2026-11-09）

每次生成前读取素材库中最近7天至今的真实发布日期，检查标题、开头、主要卖点组合、场景和封面短字；不得照搬，也不得仅换型号、emoji或同义词。参考图可借结构、节奏与配色，内容须另选切口。同批成稿也互相避重；标题/正文达到机器相似阈值会拒绝并在已有有限重写次数内重新生成，仍雷同则明确失败。语义层面的相似仍需人工复核。未知发布日期不冒充旧帖；抓取时间不是发布时间。

自动参考保留平台、合集、版式、人工精选与型号相关性约束；在同等候选中倾向同账号互动较好的帖子。只根据真实可见的点赞、收藏、评论及带时间的快照计算相对权重，未知指标不记为0；不足样本和互动量不加权。发帖时长与后续增长用于修正比较，不称已证明爆款、曝光、转化或效果因果。不复制热帖的原文、数字、旧活动或能力承诺，不因热度放宽风险词。策略参数唯一在 config/data-cleaning.json 的 monitoring 节；原始日期与互动快照只维护在 data/posts.jsonl。

目标账号与采集入口沿用 data/sources/bookmarks-raw.json。每日北京时间0点读取新近图文并刷新已入库帖的互动；遇登录失效、验证码或访问限制即停并报告缺口。近7天新帖按ID去重入库；旧帖保留用户维护的正文、图片、精选和合集，仅补日期及互动。未分类新帖不擅自加入四大人工合集。
