# 平台规则

> **最近更新时间：2026-11-04**（已同步 Kimi K3.1 Pro & Highspeed、GLM-5.3 协作记录：标题≤20字、跨模型换 emoji、开头≤两行、一对N大白话去重、三套递进结构、价格反差板块与合规工具替换）

来源：lilith 2026-11-01 口述（D10）+ 平台公开规范。T04 从企微提炼后补充；2026-11-04 蒸馏更新。

## 小红书

**调性**：普一点，不油腻，不偷袭。白话解释：
- 普一点 = 像普通用户在分享，不像品牌在喊口号。少用「重磅」「震撼」「炸裂」。
- 不油腻 = emoji 克制（每行最多一个）、不连用三个感叹号、不「宝子们」「姐妹们」开头。
- 不偷袭 = 不蹭别人的事故、不踩竞品、不借热点骂人。

**价格表达**
- D10 基础可选话术：便宜管饱、管饱管够；「便宜量大」也在用户候选中。
- 用户补充候选：白菜价、便宜量大、便宜接入、便宜畅玩、便宜敞开用、便宜放开跑、真香价、优惠价、特惠价。按场景选用，不要求四字，单行保持字号色块协调。
- **禁区说明**：小红书禁止具体几折、具体金额、极限词及「量大管饱」。具体正则与替换建议统一维护在 `banned-words-quick.yaml`，本文件不作重复维护。

**封面（大字报）**：见 `design-rules.md`。

**正文（移动端短句）**（Lilith 2026-11-03 / 2026-11-04 更新）：
- **标题与开头字数**：小红书标题严格控制在 20 字以内（含标点与 emoji）；不同模型批次必须更换标题与列表 emoji，不与上一模型雷同。开头引入句控制在手机端两行以内（约 25–34 字），避免多出几个字掉到第三行。
- **一对N去重与大白话**：同批写多篇文案前，先梳理当前模型的真实主能力（如 Kimi K3.1 Pro 的长程代码工程、原生 3D 建模、金融财报降幻觉、通用长程 Agent；GLM-5.3 的生产级长程编程、涌现级代码安全审计、长程通用 Agent），为每个特点准备多个不同角度的大白话形容，每篇各取一个，确保第一眼看得懂且不重样。
- **三种递进结构与极简表达**：支持三类常用结构——① 开头简单引入＋卖点＋价格板块＋钩子；② 开头简单引入＋卖点＋价格板块＋能接到哪里用（兼容 CC 及 ZCode、Trae、WorkBuddy、扣子等国内合规工具）＋适用场景＋钩子；③ 开头简单引入＋卖点＋价格板块＋能接到哪里用＋适用人群＋钩子。每条卖点一句话点透（约 15–22 字），不啰嗦；价格板块用两行短句突出「能力升级、开销降低 / 路径更短更省额度」的反差感，并与封面图文字呼应。

每行以 15–20 字为参考，上限 20 字，短句分行；一个意思可占数行，段与段之间必须空一行。卖点直接短句成段，或用少量 `▫️` / `▪️` 点缀，不要求每行 emoji。严禁连续多行「emoji + 四字标题 + 冒号 + 长句说明」的简历/PPT 排版。

正文不单列「适合人群：……」说明书尾巴；人群自然融入结尾行动号召。`audience` 保留在投放元数据，不由 Markdown 渲染器另行拼接。末尾标签包含完整模型名及相关场景/人群词；数量由生成任务的结构约束确定。这里的「短句」指手机阅读的留白节奏，不堆辞藻，不写大段说明文。

**参考样本**：思敏企微里勾选的那一长条，T04 标注后在 `data/posts.jsonl`（platform=xhs） 里 `label.good = true`。

## 闲鱼

- 像个人卖家，直给。标题就是「XX 模型 + 卖点 + 便宜」。
- 价格可以写具体；用户未提供实际金额时不自行编价，可沿用用户明确的好价、量大等服务表达。
- 好坏看「想要」人数，T02 抓回后按 `metrics.wants` 排序。
- 不要「官方」「旗舰」这种词，闲鱼用户不吃。

## 公众号

- 长文，可信，有依据。价格数字从 Model Price Watch 取，不手填。
- 排版走 `gzh-design-skill`。
- 去 AI 味走 `avoid-ai-writing` + `lieflat-less-ai-tone`。

## 通用禁区

- 小红书、闲鱼都禁用 API 字样（D18，lilith 2026-11-02 确认）；封面、文案和标签均适用。旧样本出现过不代表当前允许。
- **所有对外可见内容都禁写境外模型品牌和型号**：适用于小红书、闲鱼、公众号、群公告/社群通知，以及标题、正文、封面文字、图片 OCR 文案、标签和按钮文案。当前至少包括 GPT / ChatGPT / Codex / GPT-Image、Claude、Gemini、Grok 等；用户原文、历史样本或官方资料中出现过，也不能直接带入发布稿。
- 涉及境外模型的优惠、倍率或活动，可以保留真实活动数字，但模型名统一改成「指定文字模型」「编程模型分组」「指定生图模型」「视频模型分组」等泛称，不得用缩写、型号变体或品牌谐写绕过规则。境内模型名称仍须按事实来源和其他平台规则核验。
- 境外模型名只允许留在内部事实源、价格核对、抓取原文和风险审计记录中，并标注 `[仅事实源，不进文案]`；生成稿、预览稿和待发布素材不得出现。
- 不编数据，不编评测结果。
- 不贬低竞品。
- 风险词见 `banned-words-quick.yaml`（当前唯一机器规则源；企微证据保留在 `data/wecom/risk-words.md`）。

## 闲鱼实际观察（2026-11-01，账号「API大玩家」）

- 历史帖子显示账号曾出售模型 API 额度并使用折扣词；这是样本事实，不是当前文案许可。按 D18，闲鱼文案同样禁写 API；价格具体表达仍与小红书规则不同。
- 想要数最高的标题：Seedance2.5 好用视频模型（97）、Seedance2.5 高清视频生成（62）、Kimi K3.1 Pro 新一代模型（37）。视频模型比文本模型好卖。
- 标题公式：模型名 + 一个形容（好用 / 高清 / 免排队 / 白菜价）+ 用途（视频生成 / 模型）。15 字以内。
