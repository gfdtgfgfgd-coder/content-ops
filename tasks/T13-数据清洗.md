### 3. xianyu 标注缺失（34/34 条）

- 20/34 条 `metrics.wants: null`，但 `_ranked.md` 里有 14 条的 wants 值（352、324、97…）
- 17/34 条 cover_ocr 含「API」（闲鱼同样禁 API，按 D18 执行）

## 步骤

### 1. 补建 SKILL.md（10 分钟）

写 `skills/xhs-title-patterns/SKILL.md`，内容是把 `quick.md` 升级为标准 SKILL 格式：frontmatter（name/description）+ 正文引用 `quick.md` 的结论。不复制内容，用引用指过去，避免双份维护。

### 2. 清洗 XHS 数据：加污染标记，不动原文（1 小时）

给每条 `data/xhs/<id>.json` 加两个字段（不修改已有字段）：

```json
"signal": {
  "engagement_tier": "low|mid|high|good",
  "banned_word_hits": ["API", "量大管饱", ...],
  "banned_word_scope": "body|cover_ocr|tags",
  "clean_for_style_reference": true|false
}
```

判定规则：
- `engagement_tier`：
  - `good`：`label.good=true`
  - `high`：likes≥50 或 collects≥20
  - `mid`：有任意一个非零互动但未达 high
  - `low`：likes=0 且 collects=0 且 comments=0 且非 good（**89 条，打标但不删**）
- `banned_word_hits`：扫 body + cover_ocr + tags，命中 `rules/banned-words-quick.yaml` 的词列出
- `clean_for_style_reference`：`true` 当且仅当 `good=true` 且 `banned_word_hits=[]`。**6 条污染 good 标 false**，但 `label.good` 保持不变（入选证据是真的，只是不能当无脑样例）。

写一个脚本 `scripts/clean-xhs-data.py`，幂等可重跑，输出清洗日志（多少条命中、多少条降级）。

### 3. 解析 audience（30 分钟）

写 `scripts/parse-audience.py`：对 `audience_raw` 非空的 33 条，把「👥 适合人群：A、B、C」拆成 `audience: ["A","B","C"]`。空 `audience_raw` 的不补，标 `audience: []` 不动。T09 后续可补抓更多。

### 4. 清洗 Xianyu 数据（1 小时）

写 `scripts/clean-xianyu-data.py`：

- 从 `_ranked.md` 回填 `metrics.wants`（14 条有值，20 条保持 null 并在 signal 里标 `no_wants_signal: true`）
- 给每条加 `signal` 字段：
  ```json
  "signal": {
    "wants_tier": "top|mid|low|none",
    "banned_word_hits": ["API", ...],
    "clean_for_style_reference": true|false,
    "platform_allows_api": false
  }
  ```
- `wants_tier`：top=前 5、mid=6-14、low=15-20、none=0 或 null
- `platform_allows_api: false`（D18：小红书和闲鱼都禁 API）
- 不动 `label`，新增 `signal.style_reference_rank`：按 wants 降序的序号

### 5. 修标题模板词（10 分钟）

改 `skills/xhs-title-patterns/quick.md` 的「Top5 卖点短语」：
- 把第一条「量大管饱 / 便宜管饱 / 便宜又稳定」**拆成两条**：
  - 「便宜管饱 / 便宜又稳定」（D10 允许，保留为可学样例）
  - 「量大管饱」（标注：Q7 后已禁小红书，仅作历史样本，生成不直接继承）
- 在 quick.md 顶部加一句：「以下卖点短语中标注【已禁】的，仅作历史结构参考，生成时不直接继承词句，须用 D10 允许的区块词替换。」

## 规矩

- **不删原始数据**，只加字段、加标注。所有清洗可逆，回滚就是删 `signal` 字段。
- **不改 label.good**，入选证据是真的，污染标记单独存。
- **不编数据**：audience_raw 空的不补，wants null 不猜，标 `none`。
- **幂等**：清洗脚本跑两遍结果一致，第二遍不产生 diff。
- **不改 D10**：量大管饱的口径冲突记在 `known_conflicts`，不在这张卡里翻案。
- commit message 用中文，分提交：先清洗脚本、再清洗后数据、再蒸馏、再模板修复。每步 `git push`。
