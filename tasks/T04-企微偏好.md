# T04 · 企微记录 → 思敏偏好 + 好帖标注

执行者：Codex
状态：阻塞（可用产出已交付；历史补采未完成）
依赖：企微 app 已打开，lilith 和思敏的聊天窗口已打开
开始时间：2026-11-01 晚

## 目标
从企微聊天记录提取思敏对好帖的判断标准和她勾选的好帖 id，蒸馏成 SKILL.md 供后续生成文案时使用。

## 输入
- 企业微信 app，lilith 与阮思敏的聊天窗口（已打开）
- awesome-persona-skills 仓库的 SKILL.md 格式参考（身份 / 判断标准 / 原话例子 / 禁忌 / 使用方式）

## 步骤
1. **抓取聊天记录**（2.5 小时）
   - ego 浏览器操控企微 app（或企微网页版）
   - 翻页截图，从最新往前翻，翻到 2024 年或更早（至少 500 条消息）
   - OCR 提取文本，保存到 `data/wecom/raw/<日期>.txt`（原始内容，gitignore）
   - 每截 50 屏休息 5 秒，遇验证码停止记录

2. **提取好帖与评价**（1 小时）
   - 用 Claude 读 `data/wecom/raw/` 下的所有 txt
   - 提取：
     - 思敏明确说"这个好""发这个""这条不错"的帖子链接或截图里的 id
     - 她的评价原文（"标题要有动词""别太正式""这个配色不行"）
     - 她否定的例子（"太油腻""蹭热点""像广告"）
   - 输出 `data/wecom/simin-feedback.jsonl`：
     ```json
     {"post_id": "6a30b2be...", "feedback": "good", "quote": "这个可以，标题动词用得好", "date": "2026-10-20"}
     {"post_id": null, "feedback": "bad", "quote": "别搞这种油腻的", "category": "tone", "date": "2026-09-15"}
     ```

3. **蒸馏 SKILL.md**（30 分钟）
   - 用 Claude 读 `simin-feedback.jsonl`，按 awesome-persona-skills 格式写：
     ```markdown
     ---
     name: simin-persona
     description: 阮思敏的内容偏好与判断标准
     metadata:
       type: feedback
     ---
     
     ## 身份
     阮思敏，运营，负责小红书 / 闲鱼 / 公众号内容审核与发布。
     
     ## 判断标准（好内容）
     1. 标题第一行有动词，直给，不绕
     2. 不油腻，不蹭热点骂人，普通一点
     3. 配色有层次，背景和主副标题色相拉开
     4. 价格话术"便宜管饱"可以，具体折扣不行
     5. ...
     
     ## 原话例子
     - "这个可以，标题动词用得好" —— 2026-10-20
     - "别搞这种油腻的" —— 2026-09-15
     
     ## 禁忌
     - 太正式（像官方公告）
     - 蹭热点（骂竞品、碰瓷大厂）
     - 配色单调（背景和字同色系）
     
     ## 使用方式
     生成小红书 / 闲鱼文案时，整段塞进 system prompt。
     ```
   - 保存到 `skills/simin-persona/SKILL.md`

4. **回填好帖标注**（30 分钟）
   - 读 `simin-feedback.jsonl` 里 `feedback: "good"` 的 `post_id`
   - 对每个 id，找到 `data/xhs/<id>.json`，改：
     ```json
     "label": {"good": true, "by": "思敏", "reason": "企微勾选 <日期>"}
     ```
   - 至少标注 10 条

## 产出
- `data/wecom/raw/*.txt`（原始聊天，不进 git）
- `data/wecom/simin-feedback.jsonl`（进 git）
- `skills/simin-persona/SKILL.md`
- ≥10 条 `data/xhs/*.json` 的 `label.good = true`

## 验收
- [x] `skills/simin-persona/SKILL.md` 存在，≥5 条判断标准，≥3 条原话例子
- [x] `simin-feedback.jsonl` ≥20 行
- [x] `ls data/xhs/*.json | xargs grep '"good": true' | wc -l` ≥10

## 规矩

- 进 git 的只有提炼后的 `simin-feedback.jsonl` 和 `SKILL.md`
- 评价原文去掉人名、时间等隐私，保留判断逻辑
