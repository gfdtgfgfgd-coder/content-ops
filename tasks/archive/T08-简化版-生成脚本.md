# T08-简化版 · 小红书大字报生成脚本（今天用）

执行者：Codex
状态：完成（新生图额度受限，缓存背景模式可用）
依赖：T04（思敏偏好）、T03 简化版（标题句式 + 版式）、T05 简化版（风险词）、T06（文生图）
开始时间：2026-11-01 晚

## 目标
写一个脚本，输入模型名，输出小红书文案 + 大字报封面图。今天能跑通端到端。全量版（T08 完整版）后面做公众号 / 闲鱼 / 更多平台。

## 输入
- 模型名（如 GLM5.3、Kimi 2.6、Seedance 2.5）
- 生成数量（默认 2）
- 平台（今天只做 xhs，后面加 xianyu / gzh）

## 步骤
1. **写生成脚本 `scripts/gen-xhs-post.py`**（1.5 小时）
   - 参数：
     ```bash
     python scripts/gen-xhs-post.py \
       --model GLM5.3 \
       --platform xhs \
       --count 2 \
       --output outputs/2026-11-01/
     ```
   - 流程：
     1. 读 `skills/simin-persona/SKILL.md`
     2. 读 `skills/xhs-title-patterns/quick.md`
     3. 读 `rules/banned-words-quick.yaml`
     4. 读 `rules/design-rules.md`
     5. 调 Claude API（公司网关）生成文案：
        - System prompt：塞 simin-persona 全文 + "你是小红书内容生成助手，根据模型名生成符合思敏偏好的标题和正文"
        - User prompt：
          ```
          模型名：{model}
          平台：小红书
          要求：
          1. 标题：3 行，第 1 行用动词开头（参考：{xhs-title-patterns 里的 Top5 动词}），第 2 行模型名，第 3 行卖点（参考：{卖点短语}）
          2. 正文：200 字，普通口语，不油腻，不蹭热点，可说"便宜管饱"但不说具体折扣
          3. 标签：#模型名 #AI #…（3–5 个）
          4. 适合人群：从已有帖子里提炼（先硬编码"电商商家、广告工作室、短视频创作者"，T09 后改成动态）
          
          输出 JSON：
          {
            "title": "...",
            "body": "...",
            "tags": ["#模型名", ...],
            "audience": "..."
          }
          ```
     6. 风险词检查：调 `scripts/check-banned-words.py`，命中的替换
     7. 生成大字报图：
        - 读 `rules/design-rules.md` 的配色规则
        - 构造 prompt：
          ```
          画一张小红书封面大字报：
          - 背景：[冷色 or 暖色]渐变
          - 主标题："{title 第 1 行}"，白色大字，字号约画面宽度 1/8
          - 副标题："{title 第 2 行}"，灰色中字
          - 强调文字："{title 第 3 行}"，黄色 / 红色小字，单独强调
          - 风格：扁平插画，简洁，对比度高
          ```
        - 调 `scripts/gen-image.py --prompt <上面的 prompt> --output <文件名>`
     8. 输出：
        - `outputs/2026-11-01/post-1.md`：
          ```markdown
          # {title}
          
          {body}
          
          {tags}
          
          适合人群：{audience}
          ```
        - `outputs/2026-11-01/post-1.png`：大字报图

2. **测试跑通**（30 分钟）
   - 测试 1：`python scripts/gen-xhs-post.py --model GLM5.3 --count 2`
   - 测试 2：`python scripts/gen-xhs-post.py --model "Kimi 2.6" --count 1`
   - 检查：
     - 文案里没有"最便宜""几折"等禁用词
     - 标题第 1 行有动词
     - 图片存在且非空
