# T09 · 人群标签：每条帖子标注适用人群，供广告计划定向

执行者：Codex
状态：待开始
依赖：T02（有帖子），T03 更好

## 目标
小红书和闲鱼的每条帖子都有一行「适用人群」，用于聚光 / 闲鱼推广的人群定向。既要从老帖里抽出来已有的，也要给新生成的帖子自动补。

## 输入
- `data/xhs/*.json`、`data/xianyu/*.json` 的 `audience_raw`（T02 抓到的原文行，如「适合人群：电商商家、广告工作室、短视频创作者」）
- 公司业务线（docs/02 平台区分 + Obsidian 总纲）

## 步骤
1. 汇总所有 `audience_raw`，去重归一，写 `rules/audience-tags.yaml`：每个人群一条，含 `tag`（短名）、`aliases`（同义写法）、`platforms`、`fits_models`（哪些模型类型常推给这群人，如视频模型 → 短视频创作者）、`ad_keywords`（投放时的兴趣词）。目标 15 到 30 个标签。
2. 写 `scripts/tag-audience.py`：输入帖子 JSON，输出 `audience: [tag, ...]`（规则匹配 + 调文案模型兜底），回填到 JSON。
3. T08 生成流水线在 post.md 末尾固定加一行「适合人群：…」，从该标签库取，闲鱼版和小红书版措辞各一套（闲鱼直白，小红书口语）。
4. 输出 `data/_audience-stats.md`：每个人群标签对应多少条好帖、平均点赞 / 想要，给投放参考。

## 产出
- `rules/audience-tags.yaml`
- `scripts/tag-audience.py`
- `data/_audience-stats.md`
- 所有帖子 JSON 回填 `audience`

## 验收
- 标签库 ≥15 条，每条有 ≥2 个 alias。
- 随机抽 10 条帖子，`audience` 非空且人读着合理。
- T08 产出的 post.md 末尾有人群行。

## 规矩
- 人群词不涉及敏感属性（年龄段、地域歧视、健康、收入）。只用职业 / 场景 / 用途。
