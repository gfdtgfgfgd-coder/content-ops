# T06 · 文生图 / 图反推通路打通

执行者：Codex
状态：待开始
依赖：Q3

## 目标
确认公司网关里哪些图像模型能用，写两个脚本：图反推提示词、文生图。

## 输入
- `~/.codex/config.toml` 的 custom provider（base_url、token）
- `~/.codex/cc-switch-model-catalog.json` 列出的模型

## 步骤
1. 列出网关里所有图像类模型（文生图、图生文、图编辑），写到 `docs/03-开放问题.md` Q3 下面，lilith 选。
2. 写 `scripts/img-describe.py`：输入图片路径，输出中英文提示词 + 风格标签（JSON）。
3. 写 `scripts/img-generate.py`：输入提示词 + 尺寸 + 张数，输出 PNG 到指定目录，旁边写 JSON 记录参数。
4. 用 `data/xhs/_cover-prompts.jsonl`（T03）里一条跑通端到端：反推 → 生成 → 肉眼对比，截图贴完成记录。

## 产出
- `scripts/img-describe.py`、`scripts/img-generate.py`
- `outputs/t06-test/` 测试图

## 验收
- 两个脚本 `--help` 能看，各跑通一次。
- 端到端一条，生成图与原图风格接近（完成记录贴对比）。
- token 不写进脚本，从 config.toml 或环境变量读。
