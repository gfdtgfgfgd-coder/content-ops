## 目标
查出公司网关有哪些图像模型可用（文生图 / 图反推），写脚本调通，能生成一张大字报封面图。

## 输入
- ego 浏览器书签栏「公司网址」里的网站
- 可能的模型：DALL-E 3、Midjourney、Flux、Stable Diffusion、通义万相、文心一格等

## 步骤
1. **查可用模型**（30 分钟）
   - ego 浏览器打开书签栏「公司网址」
   - 逐个网站点开，找「图像生成」「文生图」「Image Generation」入口
   - 截图保存到 `docs/gateway-models-screenshot.png`
   - 记录：模型名、接口地址、是否需要 API key、价格
   - 写到 `docs/03-开放问题.md` Q3，关闭该问题

2. **写脚本调通文生图**（1 小时）
   - 写 `scripts/gen-image.py`：
     ```python
     # 输入：prompt（中文或英文）、style（cartoon | realistic | flat）
     # 输出：图片路径
     # 调用：公司网关里找到的文生图接口
     # 示例：python gen-image.py --prompt "GLM5.3 高性能模型" --style cartoon --output test.png
     ```
   - 从网关文档或示例代码里找接口调用方法
   - 硬编码一个测试 prompt（"seedance2.5 量大管饱"），跑通

3. **图反推（可选，时间够再做）**（30 分钟）
   - 如果网关有图反推（image-to-prompt）接口，写 `scripts/reverse-prompt.py`
   - 输入：图片路径，输出：prompt_zh + prompt_en + style_tags
   - 测试：用置顶两篇的封面图反推
