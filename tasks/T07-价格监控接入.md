# T07 · Model Price Watch 接成技能

执行者：Codex
状态：待开始
依赖：无

## 目标
生成文案时能一句话取到最新价格事实，不手填。

## 输入
- `~/Documents/ChatGPT/【市场调研】/model-price-monitoring`（Nuxt，本地 3100 端口）
- 它的 `data/reports/latest.json`、`/api/` 接口

## 步骤
1. 读它的 README 和 server/api，找出：取某模型当前价、取 APIPod × OctopusX 比价、触发刷新 三个接口。
2. 写 `scripts/price.py`：`price.py <模型名>` 输出该模型各商家价格表（Markdown）；`price.py --compare <模型名>` 输出比价；`price.py --refresh` 触发刷新。服务没起时提示怎么起（README 里有 `start-local.sh`）。
3. 写 `skills/price-facts/SKILL.md`：什么时候用、怎么调、输出长什么样、价格数据的口径注意（USD、按 token 档位）。

## 产出
- `scripts/price.py`
- `skills/price-facts/SKILL.md`

## 验收
- `price.py GLM-5.2` 能出表。
- `price.py --compare GLM-5.2` 能出比价。
- 不改 model-price-monitoring 仓库任何文件。
