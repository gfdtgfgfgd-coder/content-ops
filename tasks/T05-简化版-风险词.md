## 目标
从已有规则提取 10 个禁用词，写成简化版 yaml，今天生成流水线能用。全量企微提炼版（T05 完整版）后面再做。

## 输入
- `rules/platform-rules.md`
- 决策记录 D10（小红书区块词）
- 广告法常见极限词（最、第一、顶级等）

## 步骤
1. **提取禁用词**（20 分钟）
   - 从 `platform-rules.md` 和 D10 提取：
     - 小红书禁止：具体折扣数字（几折、¥xx）
     - 小红书允许：便宜管饱、管饱管够、便宜量大
     - 广告法极限词：最便宜、第一、顶级、独家
   - 写 10 条到 `rules/banned-words-quick.yaml`：
     ```yaml
     - word: 最便宜
       level: ban
       platform: [xhs, xianyu, gzh]
       replace: 便宜管饱
       reason: 广告法极限词
     
     - word: 几折
       level: ban
       platform: [xhs]
       replace: 便宜量大
       reason: 小红书禁止具体折扣（D10）
     
     - word: ¥\d+
       level: ban
       platform: [xhs]
       replace: 低价
       reason: 小红书禁止具体价格
       regex: true
     ```

2. **写检查脚本**（10 分钟）
   - 写 `scripts/check-banned-words.py`：
     ```python
     # 输入：文案文本
     # 输出：命中的禁用词列表 + 建议替换
     # 示例：python check-banned-words.py --text "最便宜的 GLM5.3"
     # 输出：["最便宜" → 建议替换为 "便宜管饱"]
     ```

## 产出
- `rules/banned-words-quick.yaml`（10 条）
- `scripts/check-banned-words.py`
