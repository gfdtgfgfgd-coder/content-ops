# T02 · 抓取小红书 + 闲鱼帖子

执行者：Codex
状态：待开始
依赖：Q1（置顶两篇的账号 / 链接）

## 目标
把 ego 浏览器书签「素材参考」里的小红书、闲鱼帖子，加上小红书账号置顶的两篇，抓成 `data/xhs/*.json`、`data/xianyu/*.json`，图片下到 `data/images/`。

## 输入
- ego 浏览器（已登录小红书、闲鱼），书签栏「素材参考」文件夹。先运行 `ego-browser skill` 读用法。
- 小红书置顶两篇：链接见 docs/03 Q1 的答复。
- 字段格式：docs/02-架构.md「数据格式」。
- Hanabi 的小红书读取代码可参考：`~/Desktop/Hanabi完整备份_2026-10-27/01_源码与构建/content-alchemy/lib/`（只读）。

## 步骤
1. 写 `scripts/fetch-posts.py`（或 .mjs）：输入一个 url 列表文件，输出 JSON。支持 `--platform xhs|xianyu`、`--skip-existing`。
2. 先从书签导出 url 列表到 `data/xhs/_urls.txt`、`data/xianyu/_urls.txt`。
3. 逐条打开，抓标题、正文、图片 url、点赞 / 收藏 / 评论（小红书）或想要数（闲鱼）、标签、作者。
4. 图片下载到 `data/images/<platform>/<id>/`，封面另做 OCR 填 `cover_ocr`（可用 macOS Vision 或 Hanabi 里的 OCR 方式）。
5. 写 `scripts/redownload-images.py`：换电脑后按 JSON 里的 `image_urls` 重下。
6. 置顶两篇 `is_pinned: true`，`source: "pinned"`。
7. 闲鱼按 `metrics.wants` 降序生成 `data/xianyu/_ranked.md`，前 20 条标题 + 想要数 + 链接。

## 产出
- `scripts/fetch-posts.*`、`scripts/redownload-images.*`
- `data/xhs/*.json`、`data/xianyu/*.json`
- `data/xhs/_urls.txt`、`data/xianyu/_urls.txt`
- `data/xianyu/_ranked.md`
- `data/images/`（不进 git）

## 验收
- 书签里的帖子数 = JSON 文件数（差额在完成记录里逐条说明原因）。
- 随机抽 5 条 JSON，字段齐全、图片能打开、`cover_ocr` 非空。
- 置顶两篇 `is_pinned: true`。
- `_ranked.md` 存在且想要数降序。
- 重跑脚本不重复抓已有 id。

## 规矩
- 限速：每分钟不超过 10 个页面动作，每 50 条休息 5 分钟。
- 遇验证码 / 登录失效立刻停，记录到完成记录，不绕过。
- 不抓评论区用户信息（Q6 未定）。
