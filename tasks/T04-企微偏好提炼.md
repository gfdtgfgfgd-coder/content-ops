# T04 · 企微记录 → 思敏偏好 + 好帖标注

执行者：Codex
状态：待开始
依赖：Q4（lilith 告知思敏一声）

## 目标
从 lilith 与阮思敏的企业微信聊天里提炼：她认为什么帖好、什么不好、常提的风险词；并把她勾选 / 单独截出的小红书帖在 `data/xhs/` 里标 good。

## 输入
- 本机企业微信客户端，与「阮思敏」的会话。
- `data/xhs/*.json`（T02 产出，用于匹配标注）。

## 步骤
1. Codex 操控电脑打开企微会话，从最早翻到最新，逐屏截图到 `data/wecom/raw/`（gitignore，只留本机）。截图命名按序号。
2. 对截图做 OCR 成 `data/wecom/raw/transcript.md`（本机）。
3. 读 transcript，提炼三份文件：
   - `data/wecom/preferences.md`：她认为好的特征 ≥10 条、不好的 ≥5 条，每条附 1 句去敏原话。
   - `data/wecom/risk-words.md`：她或 lilith 提过「不能说」「改掉」「有风险」的词，每条附上下文一句。
   - `data/wecom/good-posts.md`：她勾选 / 单独截出 / 说「这个好」的帖子，能对上链接或标题的列出来。
4. 用 good-posts.md 回填 `data/xhs/*.json` 的 `label`。
5. 把 risk-words.md 里的词按格式追加进 `rules/banned-words.yaml`（T05 再整理）。

## 产出
- `data/wecom/preferences.md`、`risk-words.md`、`good-posts.md`（进 git，去敏）
- `data/wecom/raw/`（本机）
- `data/xhs/*.json` 的 `label` 回填

## 验收
- preferences.md 好特征 ≥10、坏特征 ≥5，每条有原话。
- good-posts.md 里能对上 `data/xhs/` 的比例在完成记录里写明，对不上的列出来。
- `rules/banned-words.yaml` 新增条目 ≥5。
- `git status` 看不到 `data/wecom/raw/`。

## 规矩
- 原文、截图、OCR 全文只留本机，不进 git，不传网关之外的任何地方。
- 提炼文件里不出现第三人姓名、客户名、金额。
- 与工作无关的聊天跳过不记。
